# Tauri Application Contract

All commands return JSON-serializable DTOs and frontend-safe `AppErrorDto` errors with `kind` and `message`.

## Packages
- `get_packages()` -> `PackageDto[]`
- `get_packages_by_operator(operator)` -> `PackageDto[]`
- `get_package_details(id)` -> `{ package: PackageDto }`

## Refresh
- `refresh_operator(operator)` -> `{ operators: OperatorRefreshDto[] }`
- `refresh_all_operators()` -> `{ operators: OperatorRefreshDto[] }`

Each operator result includes `operator`, `status`, `packageCount`, `freshness`, `lastSuccessfulUpdateUnixSeconds`, and optional `error`.

## Recommendations
- `get_recommendations(context)` -> `RecommendationSet[]`
- `get_recommendations_by_strategy(strategy, context)` -> `RecommendationSet`

Recommendation objects include strategy, rank, package id, score, metrics, and reasons generated by the Rust recommendation engine.

## Filtering
- `apply_package_filters(query)` -> `PackageDto[]`
- `search_packages(text)` -> `PackageDto[]`
- `sort_packages(sort)` -> `PackageDto[]`

Filtering, search, and sorting are performed in the Rust filtering service.

## Cache Status
- `get_cache_status()` -> `{ refreshInProgress, operators }`

Operator status hides filesystem paths and reports availability, package count, freshness, last successful update, last error, and refresh state.

## Error kinds
`invalid_request`, `refresh_failure`, `operator_unavailable`, `cache_unavailable`, `internal_failure`.
